This project examined primary healthcare access across Kano State using road-network travel time and 2SFCA analysis. I mapped where people can reach PHCs quickly, where available facilities serve high population demand, and which wards should receive greater planning attention. The analysis tested 97 possible new PHC locations. Adding the top 20 improved modeled access for about 687,356 people, but the statewide 2SFCA result increased by only 1.26%. This means new facilities can help specific underserved communities, but location alone will not solve the wider healthcare-access problem.
